# paper-writing

先读项目根目录 `paper_writing_skills.md` 中与当前模式有关的规范；从技能目录到项目根目录是 `../../../`。
具体输出模板与模式见 [执行参考](references/execution.md)，按当前请求选择模式。
“文献综述”路由到综述生成。先读 [证据与成果契约](../paper-researcher/references/evidence-contract.md) 的矩阵/综述部分，从用户指定的Zotero合集或条目读取笔记；缺关键原文时交给paper-researcher补读，不自行编造。不将截断的合集或笔记结果当作全部材料。
交付综述正文、文献矩阵、论断—文献—原文位置对应表及材料范围。区分探索性综述与论文段落型综述；不足5篇时按现有规范交付初步综述及缺失清单，不声称全面综述。发现缺失可生成补检索计划，用户请求补文献时交给literature-supplement；不因写作请求自动扩大外部检索或覆盖原稿。

## Codex 执行约定

以当前可用工具为准：文档里的 MCP 工具名是能力提示，先核对真实工具名称、参数和返回结果。工具缺失就报告缺失，不声称已检索、归档或生成文件。
按本次任务读取所需参考段落，不要一次加载全部模块。用户级 Claude 配置只作迁移来源，不在新项目中修改。
中文触发词直接路由；原先的 Task/agent 调用表示工作流职责，不意味着必须创建子代理。
不编造文献、DOI、系数、样本量或显著性；事实与推测分开，数据缺失时标明待补。
Word、PowerPoint、PDF 成稿按当前环境实际可用的文档/演示/PDF技能交付；找不到工具时提供明确的文本或源码产物，不能把大纲称为已生成的文件。旧文档中的 anthropics/skills 等为可选旧集成，不自动安装。
