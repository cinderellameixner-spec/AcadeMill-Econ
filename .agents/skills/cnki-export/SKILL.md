# CNKI 书目导出

先按 [校园路径](../../../docs/LITERATURE_SEARCH.md) 在受控Edge进入CNKI。核对当前实际工具与页面，不猜测公网接口或校园代理路径。

1. 明确用户选定论文、格式、数量与是否归档。单纯引用导出不自动写Zotero。
2. 使用当前列表/详情页的导出入口，选择实际支持的RIS、BibTeX、EndNote或引用文本格式。格式以界面为准，不把引用文本冒充机器可导入文件。
3. 核对条数、题名、作者、期刊、年份、DOI；保留缺失字段。导出文件放所属研究work，结果记录来源与日期。
4. Zotero写入使用 [归档规则](../paper-researcher/references/zotero-workflow.md)：先查重，复用父项，仅补缺失部分；通过实际可用的导入工具操作，写后读回。
5. 只有已下载PDF、笔记与证据的批次可用 `tools/zotero_archive.py`；它不是RIS解析器，也不生成阅读内容。缺连接时保留导出文件，标待归档。

下载继续使用同一Edge校园会话，不认为独立网络请求继承登录。201/409或点击导出都不能单独证明完整归档成功。验证码由用户处理，额外付费逐篇确认。
