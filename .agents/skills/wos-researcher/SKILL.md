# Web of Science 校园检索

## 校园入口

先读 [校园文献检索路径](../../../docs/LITERATURE_SEARCH.md)，在现有 `cnki-browser` 控制的 **Microsoft Edge** 中打开浙大 WebVPN，等待用户手动登录，再从“电子资源导航”点击 **Web of Science**。已登录时复用同一会话。该服务可控制一般网页；不调用虚构的 `wos-browser`，也不为英文需求启动 Chrome。

用户确认登录后核对实际导航页与数据库页面。保留导航产生的代理链接和新标签页，不硬编码公网入口或登录后的加密路径。

## 检索

1. 从用户需求提取英文概念及同义词、年份、作者/期刊、文献类型、数量与阅读目标。明确用户指定的数据库范围；否则核对当前可用库并选择适合研究的范围，记录实际范围，不能把单一子库结果说成全部文献。
2. 读取当前页面的检索模式和字段，按实际界面采用主题、标题、作者或刊名等字段。需要可复现检索时保留确切查询、布尔逻辑和筛选条件；高级字段代码先核对页面帮助，不盲套旧脚本。
3. 提交后核对结果页、命中数与条件，提取标题、作者、年份、来源、DOI、记录标识/链接、摘要可用性、被引量及全文入口。未展示的字段标记未知；不把页面可见条数当总命中数。
4. 按相关性筛选，按需排序、翻页和读取详情。引用追踪使用当前记录的参考文献、施引文献入口，记录方向与查询日期；不要使用 Google Scholar 的 data-cid 或 CSS 选择器。放宽用户指定条件前报告原因，硬性条件未经同意不变更。

## 全文与导出

- 在记录详情页点击实际全文选项，跟随出版社或学校解析入口，在同一 Edge 会话获取可访问的 PDF。Web of Science 记录不保证全文权限；无权限时保留书目并注明原因，不自动购买。
- 下载完成须核对文件存在、格式与可打开性。PDF 放所属研究 `inbox/`，书目导出放 `work/`，检索结果与笔记放 `output/`。
- 按当前导出菜单选择可用的 RIS、BibTeX 或其他实际支持格式，核对导出条数、标题、作者、年份与 DOI。没有导出工具时交付已核元数据，不声称已经入库。
- 仅在用户授权 Zotero 归档时写入；先按 DOI/标题查重，再调用当前实际可用的 Zotero 元数据导入工具，附件和笔记写入后读回核对关联。CNKI/Scholar 的旧 Connector 脚本不能当作已经适配 WoS 的导入器。
- 有全文时衔接 `paper-reader`；无全文只能作摘要级分析。

## 执行边界与交付

先核对真实浏览器工具及参数，根据当前页面快照操作，不预设固定选择器。登录、验证码或认证出现时停止依赖操作，等待用户手动处理；工具缺失时保留检索式和已完成结果，不用模拟结果补齐。

按所属研究的记录规则保存检索日期、数据库范围、查询与筛选、命中数、筛选理由、书目与全文/归档状态。被引数注明来自 Web of Science 及读取日期；不与其他数据库的数值混为同一指标。

此技能是校园路径的执行说明；登录后检索、下载、导出及 Zotero 完整链路尚待实际验收。
