# 文献证据、矩阵与综合成果

## 每篇证据记录

在所属研究work保存JSON证据记录，供阅读、综述、空白与补文献复用。最低字段：

```json
{
  "paper_id": "本批稳定ID",
  "title": "核实题名",
  "doi": "已核DOI或null",
  "source_kind": "fulltext",
  "pdf_pages": 23,
  "claims": [
    {"claim_id": "C1", "statement": "原文主张的转述", "origin": "paper", "pdf_page": 1, "printed_page": "148", "locator": "摘要", "table": null}
  ]
}
```

数值为格式示例，不作为真实论文证据。source_kind为fulltext/abstract，origin为paper/researcher/model。摘要来源使用source_url和locator，不伪造PDF页码；模型判断引用支持claim_id但不写成原文。PDF页序从1开始，印刷页码单独保存；方法和数值保留表号/列号/附录。tools/literature_state.py validate-evidence校验页界与基本字段，不能替代实际内容核验。

## 泛读、精读与矩阵

泛读笔记含书目、阅读范围、问题/动机、贡献、数据/样本、变量/方法、主要发现、作者局限、模型评价、项目关联和精读建议；带AI生成/未人工核验标识。精读扩展理论、公式、变量细节、识别假设、估计与推断、稳健性/机制/异质性、表附录、可复制条件及风险。事实与模型判断分开；缺项标未核。

阅读模式为skim/deep；对比矩阵是综合成果。矩阵每篇一行，保留旧13维（题名、期刊、年、作者、问题、数据、结论、异同、Y、X、面板、因果设计、模型），增加paper_id/DOI/全文状态/阅读层级/证据路径/用途。输入按项目合集或用户条目列表限定，默认排除笔记、附件等非论文父项；检查合集列表limit和笔记truncate，不把截断结果当全集。

## 综述

用途分探索性综述、论文段落型综述。先建立矩阵与主题分组，按问题/机制/方法写研究脉络、共识、分歧与不足；不能逐篇堆摘要。核对关键原文，确认相关性而非只依笔记关键词。输出：

1. 综述正文与范围/材料限制。
2. 文献矩阵。
3. 论断对应表：论断ID、正文位置、statement、paper_id/item_key/DOI、claim_id、页/表/附录、证据级别。
4. 纳入书目与尚缺来源清单。

原规范要求5篇作为综述最小素材；不足时交付初步综述/结构与补文献计划，不能伪造补齐。摘要材料仅支撑摘要明确内容。输入仅有个人库时写“基于本次材料”，不标系统综述、领域全覆盖或断言共识。

## 候选研究空白

按对象、理论/机制、测量、识别、边界条件、结果冲突提炼具体问题。每行保存gap_id、候选描述、类型、支持paper_id/claim_id、最相近研究、可能反证、价值与数据条件、补检索式及状态。

状态：库内缺失、候选待外检、外检后仍待验证、已有一定支持、已被研究/需要改写。作者局限/未来方向不代表尚未被后续研究解决；模型推测不当事实，负面检索结果不证明无人研究。

梳理空白请求可交候选与检索计划；只有同时请求补检索才执行外部扩展。补到直接前作或反证时更新状态，解释贡献边界变化，不为维护原选题忽略反证。

## 补文献与更新

缺失类型：基础理论、直接研究、方法/测量、最新进展、相反证据、引用不足。保存missing_id、原论断/gap_id、为何缺、查询与筛选、库内/外部来源、命中数与查询日期、候选纳入理由、全文/阅读/归档状态。

回写旧综述/空白时产生新版本，附修改位置、原因和新增证据。只请求检查缺引用时交诊断；只要补检索时交候选；下载/更新原稿按请求范围执行，避免越过用户限制。

综合分析完成不等于Zotero已写入。正文与矩阵保存output，证据与任务状态保存work，sources.md关联库和条目键，PROJECT.md与轮次记录保存研究进展。维护验收不创建假研究、不修改IDE当前研究。
