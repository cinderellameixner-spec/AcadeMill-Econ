# Scholar 全文入口

仅明确Scholar需求时使用当前Chrome工具。复用搜索结果中实际可见的PDF/HTML、出版社与DOI链接，不构造未经核验的镜像地址。

1. 核对题名、作者、年份和版本。从当前页面读取实际全文入口与DOI；未显示则标未知。
2. 优先结果中的开放全文、出版社DOI页、作者主页或机构仓储。订阅全文依用户校园权限，额外付费逐篇确认。
3. 校园会话在Edge时不能假定Chrome拥有相同登录；需校园访问则回 [校园路径](../../../docs/LITERATURE_SEARCH.md)，从实际资源导航进入。
4. 核对PDF/HTML内容与论文身份，检查文件、页数与可读性，按所属研究归档。预印本与发表版分别记录，不自动合并。
5. 无全文时保留链接与原因，仅摘要级分析。获得全文并授权阅读时交给paper-reader；授权归档按 [Zotero规则](../paper-researcher/references/zotero-workflow.md)。

工具或选择器缺失时保留已完成结果；真正可见验证码交用户处理，不自动绕过。
