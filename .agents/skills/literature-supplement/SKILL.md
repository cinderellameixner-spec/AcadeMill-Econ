# 补充缺失文献

读取 [文献协同指南](../../../docs/LITERATURE_WORKFLOW.md) 与 [证据与成果契约](../paper-researcher/references/evidence-contract.md)。下载归档执行 [Zotero规则](../paper-researcher/references/zotero-workflow.md)。

1. 确定研究归属、现有综述/笔记版本、文献范围、语言和数量上限。将缺失拆为基础理论、直接相关研究、识别/测量方法、最新进展、相反证据或具体论断的引用不足。
2. 为每项写明要验证的问题、已有支持和可能反证、所需来源类型、中英文检索式与优先级。未核实题名只记为检索线索，不列作正式参考文献。用户只要补检索计划时在此交付，不执行外部检索。
3. 先用当前Zotero工具查指定合集与允许扩展的库内范围，读取已有笔记；语义检索先检查索引，索引不可用时采用关键词/字段检索，不自动改全局配置。
4. 未覆盖部分交给paper-researcher：中文CNKI、英文Web of Science，均通过Edge的浙大WebVPN实际导航入口。保留确切检索式、范围、日期、命中数和纳入/排除理由；按需要追踪参考文献与施引文献。用户指定条件未经同意不放宽。
5. 达到用户数量/范围后交付；无上限时默认本轮最多5篇新增文献，报告剩余问题，不无限递归补检索。采用新近直接研究和相反证据，不仅依赖被引量或可下载性。
6. 用户要求“补充文献”时展示并核实候选；只有下载已获授权才获取全文。下载后按已启用协同默认查重归档和泛读；仅摘要的来源保留对应状态。
7. 交付缺失项—补充文献—来源核验—阅读/归档状态对应表，以及新文献如何支持、削弱或否定旧判断。用户要求更新综述/空白时产生新版本并交给paper-writing/topic-selection，否则只提交修订建议，不覆盖原稿。

正文缺引用并不意味着任意相近论文都能支撑它；核对实际论断和原文证据。仍找不到合适来源时标记“论断待核验”，提出删改建议，不能编造书目或页码。
