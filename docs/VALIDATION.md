测试仅使用临时PDF、临时研究目录和模拟Zotero，不连接真实库：

- 研究ID分配、轮次、项目隔离、无效ID拒绝与时间记录。
- 证据来源类型、PDF页界、HTML转义、分阶段状态与稳定键。
- 只读计划不创建条目或状态文件，重复归档不重复上传/建笔记。
- 上传失败保留父项与笔记，恢复只补缺失阶段；精读不标为泛读。
- 来源身份与版本核对、批次冲突在写入前拒绝。
- 技能元数据、相对文档链接、Python语法、配置模板和私人路径排除。

## 待验证与能力限制

- WoS已建立技能和导航流程，实际检索、导出、出版社全文与归档完整链路尚待用户环境验收。
- Scholar保留可选技能，未作为本次端到端验收范围。
- 综述、空白、补文献已定义证据契约，完整主题覆盖和外部新颖性验证须在真实研究中完成；少量样本文献不能代表领域共识。
- PDF提取不含OCR；全文索引或工具返回可能截断，精读须核对覆盖。
- Web API辅助工具仅支持明确选择的个人库、根合集与journalArticle，不处理群组库、自动合并版本、RIS/BibTeX解析或生成笔记。无DOI须提供已核年份；无文本PDF先完成独立OCR核验，不直接作为全文批次。
- 云端写入不保证桌面已同步；存储配额、网络与权限可能导致部分完成。
- 不包含实证数据、Stata运行验收、Office导出或外部插件安装。离线测试不能替代浏览器及真实库验收。

## 人工验收方法

先只读检查工具与库，用明确授权的一篇文献测试。校园从实际导航进入，核对筛选和下载文件；归档先查重、核对身份，写后读回父条目/子项/笔记并分别检查云端和桌面。失败保留本地成果及状态，不反复新建父项。不要为安装检查自动写库或购买文献。
