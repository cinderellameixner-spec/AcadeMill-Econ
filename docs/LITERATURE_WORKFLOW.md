# Zotero文献协同：功能与使用

执行入口是项目内AI会话与技能，不是独立后台服务。浏览器访问遵循 [校园路径](LITERATURE_SEARCH.md)。使用当前ChatGPT/Codex已连接的Zotero工具；克隆仓库本身不会安装插件。

## 启用与授权

新使用者默认只执行当次明确要求的检索、下载、归档或阅读动作。可说：“启用文献协同，本模块新选定文献下载后默认查重、归档到我指定的Zotero合集并泛读。”将非敏感偏好保存在本地 `LOCAL_PREFERENCES.md`，明确库、合集与作用范围；不保存密钥。既有持续授权无需每步重复确认，撤销或当次限制立即生效。

## 默认行为

- 仅检索：展示候选、范围与理由，不自动下载、写库或阅读。
- 已启用协同后，本模块新选定文献下载成功：默认核对PDF、查重、归档到指定合集并泛读。未启用时只执行当次明确动作。仅下载、不写Zotero、不阅读优先；不扫描旧下载目录。
- 仅导入：查重和归档；有“仅导入/不阅读”就不生成笔记。
- 泛读与精读是两种阅读模式；对比、矩阵、综述、空白分析是综合操作。精读由用户指定，模型可以推荐精读名单并说明理由。
- 单条请求对其中明确动作提供持续授权，不逐步反复确认。人工登录、真正可见验证码、额外付费和明确缺失的研究归属分别按实际需要处理。

## 功能入口

| 功能 | 输入与成果 | 示例 |
| --- | --- | --- |
| 归档 | PDF/书目；查重后的文献条目、附件、合集与状态 | 下载这两篇并归档到R002 |
| 泛读 | 一篇/一批论文；结构化笔记与精读建议 | 泛读R002合集新加入的论文 |
| 精读 | 指定论文与关注问题；详细笔记及证据位置 | 精读这篇，重点分析变量与识别 |
| 对比/矩阵 | 已读文献；研究问题、方法、结论、分歧与脉络 | 对比三篇论文，生成文献矩阵 |
| 文献综述 | 主题、材料范围与用途；正文、矩阵、引用对应表 | 用R002笔记生成开题报告文献综述 |
| 研究空白 | 问题、矩阵与笔记；候选空白、最相近研究、反证与验证计划 | 梳理3个候选研究空白 |
| 补文献 | 缺失清单或现有综述；补检索、来源核验、更新说明 | 补充最近三年的直接研究与相反证据，最多5篇 |
| 文献库问答 | 指定合集/问题；有出处的回答与尚缺证据 | 我的文献库有哪些论文使用分批DID？ |

## 阅读与保存

泛读快速通读，聚焦问题、贡献、数据、方法、发现、作者局限、研究关联；重要细节回到原文核对。精读系统展开理论、变量、识别假设、回归、稳健性、机制、异质性、附录及可借鉴之处。原文、研究者输入与模型判断分开。

只有摘要时生成“摘要级阅读记录”，不计为泛读或精读完成。全文工具可能受页数限制，精读须核对覆盖，不能把前几页当整篇；扫描PDF未实现OCR时报告限制。

文献父条目下挂PDF、通用泛读/精读子笔记；与研究相关的判断另建带研究ID的项目关联笔记。同一论文加入多个合集时复用父条目。AI阅读状态使用“AI泛读完成/AI精读完成”，用户已读仅依用户说明记录。

正式研究PDF保存在项目inbox/，笔记Markdown与综合成果保存在output/，缓存和状态保存在work/，检索与来源写入sources.md。用户指定桌面等位置时尊重该位置并登记，不擅自搬走。模块验收材料放根work/，不混入当前IDE研究。

## Zotero协同执行

使用当前GPT/Codex会话提供的Zotero工具；先核对库与合集，按DOI再按标题/作者/年份查重。空搜索、模糊匹配或旧Connector 409不能单独证明不存在/归档成功。已有条目复用并仅补缺失部分，不自动合并相似版本。

书目优先核数据库记录与PDF首页，DOI补全不能覆盖已核中文作者/期刊。实际工具支持本地PDF导入、书目导入、合集和子笔记，但可读不等于可写。GPT工具为只读或缺补附件操作时，可用本项目tools/zotero_archive.py，经既有凭据向同一个人库安全写入。无法写入时保留父条目并标“附件待补”，不得重复造父条目。

每篇分别记录书目、PDF下载、Zotero附件、阅读、笔记写入、合集核验状态；失败后从成功部分恢复。写入后读取父条目、子项和笔记核对，再标完成；上传失败不影响已保存本地PDF和阅读成果。

## 综合分析

综述围绕问题、机制或方法组织，输出正文、矩阵、论断—文献—原文位置表；说明输入文献与检索覆盖。材料有限时交付初步综述，不宣称领域共识或系统综述。

空白清单须列支持证据、最相近研究、可能反证、研究价值、数据条件与验证状态。库中没有、作者未来方向、领域未充分解决是不同状态；外部查重前只记候选。

补文献先查Zotero，再走校园CNKI/WoS。按具体缺失进行理论、直接研究、方法、新进展、相反证据或引用补检索；逐篇核实来源。新文献可以否定旧定位，更新时保留版本与变更说明。
